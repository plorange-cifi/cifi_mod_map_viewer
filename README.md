# Loop Mod Map Planner

An interactive map for exploring and planning your Loop Mod progression.

The goal is to make planning upgrades easier by putting the skill tree directly onto the game map, allowing you to see available progression at a glance and experiment with different levels of investment.

## Features

* **Interactive game map** — Explore the Loop Mod skill tree in the same visual layout used by the game.
* **See your progression** — Quickly see how far you can currently progress through each mod.
* **Preview future progression** — Compare your current progression with what could become available after gaining additional MP.
* **Easy-to-read mod information** — Mod levels and progression are displayed directly on the map.
* **Visual differentiation** — Different types of bonuses are visually distinguished so you can quickly identify what a mod provides.
* **Large-number support** — Costs remain readable even as progression reaches extremely large values.
* **Plan your upgrades** — Use the map as a visual aid when deciding which mods to prioritize next.

## Getting Started

Open the map and explore the available mods.

The map shows each mod in its location within the skill tree, along with its current and potential progression. Use this information to decide which upgrades are worth pursuing and how you want to develop your build.

## What This Project Is For

The Loop Mod system contains a large number of interconnected upgrades, making it difficult to understand your available progression from numbers alone.

This project is intended to provide a more intuitive way to:

* Understand the overall shape of the skill tree
* Find interesting upgrade paths
* See which upgrades are currently within reach
* Compare current progression with future progression
* Plan where to spend MP
* Experiment with different approaches to progression

## Project Direction

The long-term goal is to turn the map into a full build-planning tool rather than simply a visualization.

Potential future features include:

* Interactive mod purchasing
* Persistent builds
* Save and share codes
* Shareable builds through links
* Browser-based save states
* Upgrade recommendations
* Build comparison
* Progression and ranking tools
* More detailed mod information
* Integration with additional game data

## Status

This is an early version focused on providing a useful interactive map and progression overview. More planning and build-management features are expected to be added over time.
